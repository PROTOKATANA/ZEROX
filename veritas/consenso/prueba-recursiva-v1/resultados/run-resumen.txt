== §2 · VALIDEZ ≠ SELECCIÓN ==
Pregunta: ¿puede un nodo nuevo comprobar, SIN el DAG, que ninguna rama
competidora tiene más blue_work? La prueba recursiva sólo acredita validez.

H1: 40 bloques, canónica = 39, blue_work = 4083388403051261562353178591328542158483
H2: 41 bloques, canónica = 41, blue_work = 4083388403051261562519717176475655434646
verifica_prueba_validez(H1) = true   verifica_prueba_validez(H2) = true
H1.canonica != H2.canonica : true
blue_work(H2) > blue_work(H1) : true

Puntas de H1 (por blue_work): NamedTuple[(tip = 39, blue_work = 4083388403051261562353178591328542158483, blue_score = 0x0000000000000020), (tip = 40, blue_work = 3913247219590792330639938031686367604372, blue_score = 0x0000000000000020), (tip = 24, blue_work = 3062541302288446171630433397249949569474, blue_score = 0x0000000000000013), (tip = 20, blue_work = 2722258935367507708078647627476809503522, blue_score = 0x0000000000000010)]
Puntas de H2 (por blue_work): NamedTuple[(tip = 41, blue_work = 4083388403051261562519717176475655434646, blue_score = 0x0000000000000024)]

H2 = H1 + un bloque válido Y que fusiona las puntas de H1. Ambas historias
son válidas y sus pruebas de validez verifican. Un nodo que recibe sólo
π(H1) no puede distinguir el mundo en que la red sigue H1 del mundo en que
el adversario RETIENE H2: su vista es idéntica y la punta correcta difiere.
Por tanto ninguna prueba que sólo acredite validez decide la canónica.
Es exactamente la laguna de D5 de PPP-v0.1, con otro traje.

##### ORCHARD #####
== §3.4 · ¿Halo2 en el árbol de dependencias = recursión disponible? ==
SPEC §9 fija `orchard = "=0.15.5"`; Orchard es Halo2 sobre el ciclo
Pallas/Vesta (SPEC.md §9; research/orchard-bundle.md:58,100).
Hechos comprobados en fuentes:
  - halo2_poseidon P128Pow5T3: ancho 3, R_F=8, R_P=56 (80 S-boxes/perm).
  - Halo2 es un sistema de prueba; su libro describe compromisos/FFT/MSM y
    el argumento de producto interno, NO un mecanismo de recursión.
  - La recursión exige implementar el VERIFICADOR dentro del circuito y un
    sistema PCD/IVC (Kimchi/Pickles en Mina). Eso no viene con `orchard`.

Conclusión: el ciclo Pallas/Vesta es una condición NECESARIA —no hay que
cambiar de curvas— pero NO es un sistema de recursión utilizable. Tener
`orchard` en el árbol sólo aporta la primitiva Poseidon y el probador Halo2.
