Artefactos generados con `POAS_GUARDAR_FIXTURE=1`: `fixture.txt` contiene todos los
campos de las tres soluciones y el contexto sintético recibido por el verificador.
La salida `Debug` es un formato de inspección fijado por el código, no una
serialización canónica de consenso. `validacion.txt` conserva la ejecución final.
El SHA-256 de `fixture.txt` identifica conjuntamente parámetros, soluciones y
resultados esperados; no es un TicketId propuesto.
