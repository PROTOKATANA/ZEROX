# zx-wallet

Wallet prevista para transferencias transparentes y blindadas: claves, direcciones, viewing
keys, witnesses, generación de pruebas y almacenamiento de claves.

Esqueleto sin lógica. La capa blindada Orchard/Halo2 forma parte del destino, no de las
prestaciones ya implementadas. Estado del proyecto: [MIGRACION.md](../../MIGRACION.md).
